# Canvas Power App + Power Automate Flow Lab

Build a **Canvas Power App** that reads and writes maintenance requests and calls a
**Power Automate cloud flow** to send a confirmation email. ~35 minutes, beginner
level.

Choose the data source you want to use — the two variants are otherwise identical:

- **[Dataverse variant →](lab-dataverse.md)** — store requests in a custom
  **Dataverse** table.
- **[SharePoint variant →](lab-sharepoint.md)** — store requests in a
  **SharePoint list** (saved to My lists / OneDrive).

Both variants share the screenshots in [`images/`](images/).
